## 14. 课堂练习：30 分钟完成一次医疗 GitHub 入门闭环

### 练习目标

让医护人员完成一次完整流程：找项目 → 看 README → 判断风险 → 收藏 → 让 AI 解释。

### 步骤

1. 打开 GitHub；
2. 搜索 `medical ai` 或 `pubmed literature review`；
3. 选一个 README 看起来清楚的项目；
4. 记录项目名称和链接；
5. 看 Star 和最近更新时间；
6. 看有没有 Releases；
7. 看 README 是否写了数据来源和使用边界；
8. 看 Issues 里有没有安装失败或医学风险反馈；
9. 点 Star；
10. 把 README 复制给 AI，用本教材的提示词解释。

### 练习记录模板

```markdown
## 我今天看的医疗 GitHub 项目

- 项目名称：
- 项目链接：
- 它解决什么问题：
- 面向人群：医生 / 护士 / 科研人员 / 工程师 / 其他
- Star 数：
- 最近更新时间：
- README 是否清楚：清楚 / 一般 / 不清楚
- 有没有 Release：有 / 没有
- 是否说明数据来源：有 / 没有
- 是否说明隐私和安全边界：有 / 没有
- 是否可能用于临床：不能 / 仅研究 / 不确定 / 明确临床产品
- 我是否点了 Star：是 / 否
- 我最看不懂的地方：
- AI 帮我解释后的理解：
- 是否值得继续研究：值得 / 暂时不值得
```

## 15. 医护人员的 GitHub 学习路线

### 今天就能做

- 注册 GitHub；
- 创建一个 Private 仓库；
- 搜 3 个医疗 AI / 文献 / 科研工具项目；
- 点 Star；
- 用 AI 解释一个 README。

### 这一周完成

- 学会看 README；
- 学会看 Release；
- 学会看 Issues；
- 学会判断项目是否有隐私和临床边界；
- 下载一个公开 demo；
- 写一个简单学习笔记。

### 这个月完成

- 学 Markdown；
- 写自己的第一个 README；
- 把一个虚构数据的教学 demo 放到 GitHub；
- 建立医疗 AI 项目收藏库；
- 尝试提一个文档类 Issue。

### 进阶阶段

- 学 Git 基础命令；
- 学会 clone、commit、push；
- 学会 Fork；
- 修改一个 README；
- 提交第一个 Pull Request；
- 用 GitHub Pages 做个人科研主页；
- 用 GitHub Actions 自动更新文献或报告。

## 16. 最后总结：GitHub 是医护人员进入医疗 AI 的基础入口

对医护人员来说，GitHub 不是为了让你马上变成程序员。

它首先是一个能力：

> **看懂工具、判断质量、识别风险、复用开源成果、展示自己的项目。**

在医疗 AI 和临床科研里，这个能力会越来越重要。

你先做到下面 6 件事，就已经入门：

1. 看懂仓库页面；
2. 优先读 README；
3. 会区分 Release 和源码；
4. 会判断项目是否维护、是否有风险边界；
5. 会 Star、下载、提 Issue；
6. 会把自己的学习项目或教学 demo 放进仓库，并写清楚隐私和临床使用边界。

最后记住一句话：

> **医护人员学 GitHub，不是为了炫技，而是为了在 AI 时代更安全、更专业地理解和使用开源工具。**
