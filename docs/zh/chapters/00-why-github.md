## 0. 先说结论：医护人员为什么要学 GitHub？

很多医护人员第一次听到 GitHub，会觉得：

> “这不是程序员才用的吗？我只做临床、科研、教学，为什么要学？”

但在 AI 时代，GitHub 对医护人员越来越重要。

因为很多新东西不会先出现在教材里，而是先出现在 GitHub 上：

- 医疗 AI 项目的代码；
- 临床研究的统计脚本；
- 论文复现代码；
- 影像分割模型；
- 病历文本处理工具；
- 医学知识库构建工具；
- 医院内部小工具的原型；
- 文献综述自动化脚本；
- R / Python 数据分析模板；
- AI Agent、MCP、自动化工作流。

如果你完全看不懂 GitHub，就会错过很多一手工具和方法。

更重要的是：

> **医护人员不一定要一开始就成为程序员，但需要具备“看懂、判断、复用、验证开源工具”的能力。**

这就像你不一定要会制造监护仪，但你要知道监护仪读数怎么看、报警意味着什么、什么情况下不能盲信。

GitHub 也是一样。
